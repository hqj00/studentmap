# 05 功能规格 · 智能符号设计（F3）

- 对应需求：FR-3.1 ~ FR-3.6
- 定位：**独立页面**，与 F2「符号设计向导」（五步工作流）并列、互不干扰；两页共享同一个符号库。

## 1. 功能概述

学生用一句自然语言描述需要的地图符号（如"我需要一个加油站的点状符号"），系统直接搜索现成矢量符号并网格推荐，点选即入库——跳过 F2 的五步流程，面向"快速找到可用符号"的场景。

## 2. 数据源决策（重要）

需求原文为"直接去 iconfont 里面查找"。**2026-10-17 实测结论：iconfont 没有可调用的公开搜索 API**——
`/api/icon/search.json` 无论是否携带会话 Cookie 均返回站点 HTML 壳（页面加载了 baxia/AWSC 反爬组件），
无法稳定、合规地在应用内拉取其素材数据。

因此本期采用双通道：

| 通道 | 承担 | 说明 |
|------|------|------|
| **Iconify 公共 API**（api.iconify.design） | 应用内搜索与推荐 | 聚合 200+ 开源图标集（Material、Tabler、Solar 等），免密钥、CORS 开放，**静态托管（GitHub Pages）也能直接用**，免部署代理 |
| **iconfont 直达链接** | 补充入口 | 按关键词打开 `https://www.iconfont.cn/search/index?q=...`（新标签页），学生可在 iconfont 站内挑选，再走 F2 向导精修入库 |

后续若 iconfont 开放平台提供正式 API，可在 `src/modules/symbol/iconify.ts` 同位置替换数据源，页面无需改动。

## 3. 流程与交互

```
描述（自然语言）→ 关键词转换（本地地物词库 zh→en）→ Iconify 搜索
→ 候选网格（图标 + 名称）→ 点选 → 自动下载 SVG → 规范化校验（复用 F2 校验器）
→ 确认入库（名称默认取描述，分类默认点状，来源 iconify）→ 成功提示
```

- **输入**：描述输入框 + 常见地物快捷词 chips（加油站/医院/学校…，点击即搜）。
- **关键词转换**：`toQuery()` 命中词库返回英文（Iconify 搜索对英文效果最好）；未命中且输入含中文时原样尝试，并提示"可换用地物名词"。
- **候选网格**：图标以 `<img>` 直引 Iconify SVG URL（懒加载），卡片显示名称；点击卡片进入选中态。
- **选中入库**：选中卡片下方展开确认区（SVG 预览、名称、分类、标签选填）；「确认入库」时拉取 SVG 文本 → `checkAndNormalizeSvg` → 有错误级问题则提示不入库，否则写入共享符号库。
- **异常**：网络失败/0 结果 → 提示并给出 iconfont 直达按钮兜底。

## 4. 数据与复用

- 复用 `useSymbolLibrary()`（localStorage 键不变，`studentmap.symbols.v1`），与 F2 页符号库互通。
- `SymbolSource` 新增 `'iconify'`（显示名「Iconify 开放图标」）。
- 校验完全复用 F2 的 `checkAndNormalizeSvg`。

## 5. 许可与合规

- 页面固定提示：图标来自 Iconify 聚合的开源图标集（Apache-2.0 / MIT / CC BY 4.0 等，按各图标集协议），课程作业使用请注明来源；入库记录 `source='iconify'` 以便溯源。
- iconfont 素材遵循其站点许可（沿用 F2 步骤②的提示）。

## 6. 验收用例

| # | 操作 | 期望 |
|---|------|------|
| 1 | 输入"加油站"搜索 | 网格出现 gas-station 类图标（词库转 gas station） |
| 2 | 输入词库外中文（如"观星台"） | 原样搜索；0 结果时提示换词 + 显示 iconfont 直达按钮 |
| 3 | 点选某图标 → 确认入库 | 符号库新增记录，source=iconify，刷新后仍在（与 F2 共享） |
| 4 | 断网搜索 | 报错提示，不白屏 |
| 5 | 点「去 iconfont 搜索」 | 新标签打开 iconfont 搜索结果页且关键词正确 |

## 7. 演进

- 接入大模型优化检索词（经 ai-proxy，把长描述提炼为 1~2 个英文关键词，并给风格建议）；
- 按符号分类（点/线/面）过滤结果集；
- 批量选用入库。
