# 02 功能规格 · 地图投影智能推荐

- 对应需求：FR-1.1 ~ FR-1.8
- 流程图：[diagrams/projection-recommend-flow.mmd](diagrams/projection-recommend-flow.mmd)

## 1. 功能概述

学生输入**制图区域范围**与**地图用途**，系统通过「规则引擎 + 通用大模型」双通道输出投影推荐：
规则引擎保证离线可用、结果可解释；大模型提供自然语言解释与更细致的参数建议。
推荐结果以卡片形式展示，并（规划）支持 d3-geo 投影预览与 Tissot 变形分析。

## 2. 用户故事

- 作为一名学生，我输入「中国全图 + 统计专题图」，希望得到阿尔伯斯等积圆锥投影推荐，并知道标准纬线应设为 25°N、47°N，中央经线 105°E，以及为什么这样选。
- 作为一名学生，我选择「世界 + 教学挂图」，希望得到 Robinson / Winkel Tripel 这类折中投影的推荐与对比说明。
- 作为一名学生，当大模型服务未配置时，我仍然能得到基于规则的推荐，并能看出结果来自规则引擎。

## 3. 输入 / 输出定义

### 3.1 输入

```ts
// 区域范围：二选一
type RegionInput =
  | { kind: 'extent'; extent: RegionExtent }   // 自定义经纬度包围盒
  | { kind: 'preset'; presetId: string }       // 预设区域（世界/中国/北京/青藏高原/极地…）

interface RegionExtent {
  minLon: number  // -180 ~ 180
  minLat: number  // -90 ~ 90
  maxLon: number
  maxLat: number
}

// 地图用途
type MapPurpose =
  | 'general'      // 普通参考图/挂图
  | 'navigation'   // 航海、航空导航
  | 'statistic'    // 统计专题制图（面积敏感）
  | 'education'    // 教学演示
  | 'topographic'  // 大比例尺地形图
  | 'meteorology'  // 气象图
  | 'polar'        // 极地地区制图
```

校验规则：经度 −180~180、纬度 −90~90、min < max、包围盒非零面积；预设区域 id 必须存在。

**预设区域清单**（v0.2 起按组组织，范围取标准四至；下拉项同时显示范围供核对）：

| 分组 | 预设 | 范围 minLon / minLat / maxLon / maxLat | 取值依据 |
|------|------|----------------------------------------|----------|
| 全球 | 世界全图 | −180 / −90 / 180 / 90 | 全球四至 |
| 中国 | 中国全图（含南海诸岛） | 73.5 / 3.8 / 135.1 / 53.6 | 四至点：帕米尔高原—黑乌汇合处、曾母暗沙—漠河 |
| 中国 | 北京市 | 115.4 / 39.5 / 117.5 / 41.1 | 北京市域四至 |
| 中国 | 青藏高原 | 73.3 / 26.0 / 104.8 / 39.8 | 高原主体范围 |
| 大洲与典型区域 | 欧洲 | −9.5 / 36.0 / 66.0 / 71.0 | 爱尔兰西—乌拉尔、地中海—北角 |
| 大洲与典型区域 | 智利 | −75.6 / −56.0 / −66.0 / −17.5 | 南北狭长国家典型 |
| 极地 | 北极地区 | −180 / 66.5 / 180 / 90 | 北极圈（66°33′N）以北 |
| 极地 | 南极地区 | −180 / −90 / 180 / −66.5 | 南极圈以南 |

### 3.2 输出

```ts
interface Recommendation {
  projection: ProjectionInfo  // 投影知识库条目（见 §5）
  reason: string              // 推荐理由（自然语言）
  source: 'rule' | 'ai'       // 来源标记
  confidence?: number         // 0~1，规则引擎按匹配强度给分
}
```

主推荐 1 条 + 候选至多 3 条；每条含：名称（中/英）、类别、变形性质、关键参数、理由、来源徽标。

## 4. 推荐逻辑

### 4.1 总体策略：双通道融合

```
输入 → 规则引擎（必跑，产出候选集+理由+参数）
     → 若启用 AI：把候选集 + 知识库摘要 + 输入 发给大模型
       → 成功：AI 排序与解释融合规则理由（source: 'ai'）
       → 失败/超时(120s)：降级为规则结果（source: 'rule'）
```

### 4.2 规则引擎判定表

设：中心纬度 φc、纬度跨度 Δφ、经度跨度 Δλ、形状比 r = Δλ·cos(φc) / Δφ。

**第一优先级 —— 用途硬规则：**

| 用途 | 判定 | 推荐 |
|------|------|------|
| navigation | φc < 60° | 墨卡托投影（等角，等角航线为直线） |
| navigation | 极地 | 极地立体投影（Polar Stereographic） |
| topographic | 任意（尤其东西/南北狭长大区域） | 高斯-克吕格 / 横轴墨卡托（按 6° 或 3° 分带） |
| meteorology | 中纬度 | 兰伯特等角圆锥（等角，保锋面形态） |
| polar 或 \|φc\| > 60° | — | 方位类：极地立体 / 方位等距 / 兰伯特方位等积 |
| statistic | — | 等积族（见纬度带规则，面积必须等积） |

**第二优先级 —— 纬度带 × 变形性质：**

| 纬度带 | 等角需求 | 等积需求 | 一般/教学 |
|--------|---------|---------|----------|
| 极地（\|φc\| > 60°） | 极地立体 | 兰伯特方位等积 | 方位等距 |
| 中纬度（25°~60°） | 兰伯特等角圆锥 | 阿尔伯斯等积圆锥 | 等距圆锥 |
| 低纬/赤道（< 25°） | 墨卡托 | 圆柱等积（Gall-Peters） | 等距圆柱 |

**第三优先级 —— 形状与特殊场景：**

- r < 0.6（南北狭长）→ 候选加入横轴墨卡托；
- 覆盖全球（Δλ ≥ 330° 且 Δφ ≥ 100°，避免把环极的北极/南极地区误判为世界全图）→ 教学/挂图推荐 Robinson、Winkel Tripel（折中投影），统计推荐 Mollweide；
- 命中中国范围（约 73°E~135°E，18°N~53°N）且用途为 statistic/general →
  **阿尔伯斯等积圆锥，标准纬线 25°N / 47°N，中央经线 105°E**（我国全图惯例）置顶。

**置信度**：命中硬规则 0.9；纬度带规则 0.75；形状修正 ±0.05。

### 4.3 大模型接入

- **角色设定**（system prompt 要点）：你是地图学助教，熟悉地图投影的分类、变形性质与参数设置；只能在给定候选投影 id 中选择或微调参数，不得编造投影。
- **用户消息**：区域（中心纬度/跨度/形状比）、用途、规则候选集（id+理由）、知识库条目摘要。
- **输出契约**（JSON）：`{ "recommendations": [{ "id": "albers-equal-area-conic", "reason": "…", "params": { "centralMeridian": 105, "standardParallels": [25, 47] } }] }`
- **健壮性**：15s 超时；JSON 解析失败、id 不在知识库 → 视为失败并降级；所有 AI 文案在界面标注「AI 生成，供学习参考」。

## 6. 投影预览（FR-1.8）

推荐出结果后直接渲染预览图，**A/B 两个方案并排**，实现对比变形效果：

- 用 **d3-geo** 按有效参数（见 §6.1）实例化投影，`fitExtent` 到制图范围（世界全图则适配球面）；
- 叠加层：球面底色 → **经纬网**（10° 间隔）→ **Tissot 变形椭圆**（区域内 4×3 布点的等半径小圆投影结果，
  椭圆越扁、越大代表局部变形越大）→ **绿框**标出制图范围；
- 图例固定在预览图下方，说明三层含义；预览为纯 SVG，无瓦片依赖，离线可用。
- **预览导出（v0.3 起）**：预览图下方提供「下载 SVG / 下载 PNG」按钮——SVG 为矢量原图（序列化当前渲染结果，
  含全部图层与样式，可直接放入 Illustrator 再加工）；PNG 为 2 倍尺寸栅格化（适合贴入 Word/PPT 作业）。
  文件名形如 `albers-equal-area-conic-预览.svg`。导出不依赖网络，纯浏览器内完成。

### 6.1 有效参数规则（params.ts）

预览、参数展示与导出三处共用同一份「有效参数」：

- 中央经线：区域中心经度（四舍五入到 0.1°）；
- 圆锥投影标准纬线：取区域纬度向内 1/6 处两条（教学惯例）；**命中中国范围且为阿尔伯斯时沿用 25°N/47°N/105°E 惯例**；
- 高斯-克吕格/横轴墨卡托：按 6° 分带，中央经线 = (⌊中心经度/6⌋+1)×6−3；
- 极地立体：原点纬度取 ±90°；高尔-彼得斯标准纬线固定 45°。

## 7. 投影参数导出（FR-1.9）

每个方案卡片内提供导出区：

| 输出 | 内容 |
|------|------|
| EPSG | 有直接对应编号时给出（如墨卡托 EPSG:3395、Web 墨卡托 3857；高斯-克吕格按分带系列提示）；自定义参数无编号时明示「请用 PROJ4/WKT 导入」 |
| PROJ4 | 一键复制，如 `+proj=aea +lat_1=25 +lat_2=47 +lat_0=0 +lon_0=105 +datum=WGS84 +units=m +no_defs` |
| WKT | 一键复制 WKT2 `PROJCRS`，方法名带 EPSG 方法 ID（Albers=9822、LCC=9802、Mercator=9804、TM=9807、极地立体=9810、LAEA=9820、方位等距=9832、等距圆柱=9823、圆柱等积=9835）；无标准方法的折中投影（Robinson 等）省略 ID 并在界面提示 |
| 变形说明 | 卡片内的变形性质标签 + 推荐理由 + 优缺点列表即构成变形说明 |

复制成功给出提示「可直接粘贴到 ArcGIS Pro / 超图 GIS」。

## 8. 制图范围可视化框选（FR-1.10）

- 表单内常驻小地图组件（等距圆柱投影 + 经纬网 + 经纬度标注），鼠标拖拽拉框；
- 松开后把框选四角换算为经纬度（保留 0.1°，夹取到合法范围），自动切换到「自定义经纬度」并填入四至；
- 当前生效范围（预设或已框选）以绿色虚线框回显在小地图上；
- 手动输入框保留，用于精确修正。

## 9. 双方案对比与优先理由（FR-1.11）

- 取推荐列表前两名（方案 A = 主推荐，方案 B = 备选），并排两列卡片展示：
  预览图、变形性质、类别、有效参数、推荐理由、优点/缺点列表（知识库字段 `pros`/`cons`）、参数导出区。
- 卡片下方固定「为什么优先方案 A？」结论文本，由模板生成：
  A 的变形性质 + A 推荐理由 + B 的优势（pros[0]）与短板（cons[0]）+「用途变化可切换 B」。
- 知识库每条投影维护 `pros` / `cons` / `epsgHint` 三个字段；仅 1 条推荐时只显示单卡，不出对比结论。

## 10. 参考影像图（FR-1.13）

- 方案卡片内形成**上下结构**：上方为本应用生成的当前区域示意（经纬网 + Tissot 变形椭圆 + 范围框，§6），
  下方为该投影的**真实世界地图影像**（Wikimedia Commons 自由许可图片，`<img>` 懒加载）。
- 每张影像带标注行：投影名 + 「世界全图效果」说明 + 作者与许可（如 Strebe, CC BY-SA 3.0, Wikimedia Commons）。
- **图片自 2026-10-18 起站内自带**：12 张图已下载至 `public/ref-images/`（共约 2MB），
  知识库 `refImage.url` 使用站内相对路径 `./ref-images/<id>.jpg`——随 GitHub Pages 一起部署，
  不受外链网址变更/网络抖动影响，离线也可用；CC BY-SA 允许署名再分发，标注行即满足署名要求。
  图片来源 URL 均经 Commons API 逐一验证（温克尔三重的 Commons 文件名为英式拼写 "Winkel triple projection SW.jpg"）；
  知识库条目 `refImage` 字段（url + credit）。
- 图片加载失败时整块隐藏，不影响其他内容。

## 11. 坐标试算（FR-1.12）

- 每个方案卡片底部提供「坐标试算」区：正算（经纬度 ° → 平面坐标 x/y，米）与反算（x/y → 经纬度）。
- 计算引擎：**proj4js**，投影定义直接使用 `exporters.buildProj4()` 生成的同一份 PROJ4 字符串——
  保证「导出给 GIS 软件的参数」与「页面试算结果」严格一致。
- 默认输入取制图范围中心点；结果保留 3 位小数（米）/ 6 位小数（度）。
- proj4js 不支持的投影（如温克尔三重）：试算区显示「该投影暂不支持坐标试算」，不报错不崩溃。

## 12. 异常处理（原 §7）

| 场景 | 处理 |
|------|------|
| 经纬度越界 / min ≥ max | 表单即时校验，禁止提交并红字提示 |
| 大模型超时 / 5xx / 返回非法 JSON | 静默降级为规则结果，结果区显示「AI 不可用，已使用规则引擎」 |
| 未配置 AI 代理 | 「大模型增强」开关置灰并附说明 |
