# 功能规格：投影教学助手（自然语言驱动投影实验）

> 版本：v0.1 · 2026-10-20
> 关联：[02-功能规格-地图投影智能推荐.md](02-功能规格-地图投影智能推荐.md)（预览与参数）、[07-功能规格-投影总览与地图学问答.md](07-功能规格-投影总览与地图学问答.md)（AI 通道与降级）

## 1. 背景与目标

投影推荐解决「给我一个方案」，总览解决「有哪些投影」，但学生想观察某个现象时（例如「比较墨卡托和等地球投影在全球的变形」「以郑州为中心看方位投影」），仍要手动改区域、换投影、开图层。本功能提供**投影教学助手**：学生用一句自然语言描述想观察的现象，助手把指令解析为**结构化动作**并直接驱动投影实验台，同时给出简短解释与「已应用」回执，支持一键撤销。

## 2. 界面结构

- 投影推荐页新增卡片「② 投影实验室」，位于输入表单与推荐结果之间；
- 实验室左侧为**投影 A / 投影 B（可选）并排预览**（各带缩放按钮），上方状态行显示当前区域、中央经线、标记点；右侧/浮层为**教学助手抽屉**（按钮「投影教学助手」打开）；
- 助手抽屉：标题「投影教学助手 · 已接入大模型」、引导语「把需求说出来，让实验开始」、快捷提问 chips、对话记录、输入框；
- 每条产生动作的助手回复下方附**已应用卡片**：逐条列出区域/投影/图层/标记点的变化，并提供「撤销本次设置」。

## 3. 可控实验状态（LabState）

| 字段 | 说明 | 默认 |
|------|------|------|
| regionMode / presetId / extent | 区域：预设（world/china/beijing/qinghai-tibet/europe/chile/arctic/antarctic）或自定义四至 | 预设 china |
| projA / projB | 投影 A 与对比投影 B（B 可为空） | albers-equal-area-conic / mercator |
| overlays | 图层开关：graticule 经纬网 / tissot 变形椭圆 / land 陆地 / marker 坐标标记 | 前三个开启、标记关闭 |
| marker | 标记点经纬度（开启 marker 时绘制橙色圆点） | 无 |

## 4. 自然语言 → 动作契约

### 4.1 AI 通道

复用 AI 代理 `/ai/recommend`（spec/07 §3.2），system prompt 要求模型**只输出 JSON**：

```json
{
  "reply": "简要说明做了什么",
  "actions": [
    { "type": "setRegion", "presetId": "world" },
    { "type": "setProjections", "a": "mercator", "b": "equal-earth" },
    { "type": "setOverlays", "tissot": true },
    { "type": "setMarker", "lon": 113.6, "lat": 34.7 },
    { "type": "reset" }
  ]
}
```

- 动作类型：`setRegion`（presetId 或 extent）、`setProjections`（a/b，b 可为 null）、`setOverlays`（任一层开关）、`setMarker`（lon/lat）、`reset`；
- 服务端返回的任何非法投影 id、越界经纬度、未知动作一律丢弃；全部丢弃时按离线解析处理并如实标注来源；
- 回复气泡标注「AI 助教」。

### 4.2 离线降级（必可用）

AI 不可用或返回不可解析时，使用内置中文指令解析器，覆盖高频表达：

- 区域：全球/世界、中国、北京、青藏、欧洲、智利、北极、南极；
- 投影：18 种投影的中英文别名（如「墨卡托」「等地球」「高斯」「罗宾逊」）；
- 对比：出现「比较/对比」且提到两种投影 → A/B 并排；只提到一种 → 自动配一个对照投影；
- 图层：「变形/椭圆/Tissot」→ 变形椭圆；「经纬网/网格」→ 经纬网；「陆地」→ 陆地；「标记/位置/中心点」→ 标记；含「关闭/隐藏/取消」的短句置为关闭；
- 标记点：城市名（郑州/北京/上海/广州/成都/西安/拉萨/乌鲁木齐/哈尔滨/武汉）或「113.6E, 34.7N」形式坐标；
- 「重置/复位」→ 恢复默认状态；未命中任何关键词时给出可操作提示，不虚构动作；
- 离线回复标注「离线解析」。

## 5. 撤销

- 应用动作前保存状态快照；「撤销本次设置」恢复快照并把该回执标记为「已撤销」；
- 撤销仅对产生动作的最近一次回复生效，多次回复各自独立。

## 6. 用例与验收

| # | 操作 | 期望 |
|---|------|------|
| 1 | 打开投影推荐页 | 可见「投影实验室」：A/B 两幅预览、图层开关、助手入口 |
| 2 | 输入「切换到全球，比较墨卡托和等地球，打开变形椭圆」 | A/B 切换为墨卡托与等地球，区域变全球，变形椭圆开启；回执列出三项变化 |
| 3 | 本地未起 AI 代理时执行用例 2 | 离线解析同样完成动作，来源标注「离线解析」 |
| 4 | 输入「郑州出发距离」 | 标记点落在郑州（113.6°E, 34.7°N），标记图层开启，图上出现橙色圆点 |
| 5 | 点「撤销本次设置」 | 恢复上一状态，回执标记已撤销 |
| 6 | 输入「中国全图用阿尔伯斯」 | 区域切中国，A 切阿尔伯斯等积圆锥 |
| 7 | 输入无法识别的内容 | 回复引导语（可用示例），不产生任何动作 |

## 7. 非目标

- 不做距离量算与等距圆环（「距离」类请求仅标注位置）；
- 不做多轮上下文记忆（每条指令独立解析，当前状态随请求携带）；
- 实验室不做参数（标准纬线等）的手动编辑，仍以推荐页导出为准。
