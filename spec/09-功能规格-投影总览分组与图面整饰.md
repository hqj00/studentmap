# spec/09 功能规格：投影总览分组（中国/世界）与图面整饰

版本 v0.1 · 2026-10-21 · 状态：已实现

## 1. 背景与目标

`/#/projection` 页底部的「投影总览 · 18 幅」（spec/07）目前按"投影面类别 × 变形性质"二维筛选，
18 幅缩略图混排，且图面只有陆地与经纬网，缺少地图学教学要求的基本整饰要素。

本规格做两件事：

1. **分组**：18 幅投影按教学用途分为「中国地图投影」与「世界地图投影」两个模块展示。
2. **图面整饰**：每幅缩略图都带指北针、比例尺、图例，经纬网加经纬度标注（标清经纬网）。

## 2. 分组（中国地图投影 / 世界地图投影）

### 2.1 数据

`ProjectionInfo` 新增必填字段 `scope: 'china' | 'world'`，在 `presets.ts` 的 `PROJECTION_KB` 逐条标注。

教学归属（依据《地图学》课程惯例）：

- **中国地图投影（4 幅）**：
  - 横轴墨卡托 / 高斯-克吕格投影 —— 我国 1:1万~1:50万 大比例尺地形图国家标准（6°/3° 分带）
  - 兰伯特等角圆锥投影 —— 我国 1:100 万地形图与气象图用投影
  - 阿尔伯斯等积圆锥投影 —— 中国全图惯例参数：105°E，双标准纬线 25°N/47°N
  - 多圆锥投影 —— 国际百万分之一地图（改良多圆锥）曾用于我国地形图
- **世界地图投影（14 幅）**：其余全部（墨卡托、方位类、伪圆柱类、折中类等）。

### 2.2 展示

- 总览卡片内分两组，组标题：`中国地图投影 · N 幅`、`世界地图投影 · N 幅`；筛选后空组整组隐藏。
- 顶部计数文案「符合筛选：x / 18」保持不变；类别/性质筛选、按坐标查看、允许拖动等交互不变。
- **默认模式**下，中国组缩略图用中国全图四至（含南海诸岛，73.5°E~135.1°E / 3.8°N~53.6°N）成图：
  球面、陆地、经纬网一律裁剪到该范围（复用展示带的裁剪管线），不再画绿色范围框；
  投影参数走 `effectiveParams`（阿尔伯斯命中 105°E/25°N·47°N 惯例）。
- **按坐标查看模式**下两组行为不变（统一用坐标范围 ±55°/±35°，保留绿框与 Tissot）。

## 3. 图面整饰（每幅必备）

### 3.1 经纬网标注（标清经纬网）

- 经纬网线保持浅绿虚线样式（线宽 0.5→0.6，颜色略加深）。
- 经纬度标注随图面缩放（是地图内容）：
  - **世界全图**：经度标注沿赤道（每 60°：120°W…0°…120°E），纬度标注沿中央经线（每 30°：60°S~60°N，赤道不重复标注）。
  - **区域图（中国组 / 展示带）**：经度标注沿下边缘、纬度标注沿左边缘，间隔按跨度自适应（目标 ≤7 条，步长取 2/5/10/15/20/30/45/60/90°）。
  - 标注为 5px 深绿字、白色描边光晕；落在画幅外或被图例/比例尺/指北针遮挡的自动省略。

### 3.2 指北针

- 每幅图左上角：N 字 + 箭头图符（深绿色，白描边），不随缩放移动。
- 说明：方位/极地类投影的"北"并非全图朝上，此处按教学挂图惯例放置概略指北针。

### 3.3 比例尺

- 每幅图左下角：黑白相间线段比例尺 + 千米标注（如 `1000 km`）。
- 长度由投影中心处比例（R / proj.scale()，R=6371000 m）换算，取最接近约 52px 的整千米数
  （候选 10/20/50/100/200/500/1000/2000/5000/10000/20000 km，上限 92px）。
- 不随缩放平移，但长度随当前缩放倍率重算——任意缩放级别下比例尺始终正确。

### 3.4 图例

- 每幅图右下角：白底圆角小框，标题「图例」，行项动态：
  - 常驻：陆地（浅绿块样例）、经纬网（虚线样例）
  - 按坐标查看模式追加：制图范围（绿框样例）、变形椭圆（橙圈样例）、标记点（橙点样例）
- 不随缩放平移。

### 3.5 实现位置

- `ZoomableMap` 新增 `overlay` 具名插槽：渲染在缩放变换组之外（不随缩放移动），
  带 `:scale` 插槽属性（比例尺据此重算），`pointer-events: none` 不影响拖拽与按钮。
- `d3Factory` 新增 `buildPreviewDecorations()`：返回经纬网标注数组与投影中心米/像素；
  `buildPreviewLayers()` 新增第 6 参 `opts.clipToExtent`（区域成图裁剪）。
- 整饰只加在总览 18 幅（ProjectionGallery）；推荐方案卡预览与投影实验室不在本规格范围。

## 4. 验收

1. 总览分「中国地图投影 · 4 幅」「世界地图投影 · 14 幅」两组，组合计 18 幅。
2. 类别/性质筛选作用于两组；筛选后空组隐藏；计数不变。
3. 默认模式下中国组 4 幅显示中国全图（含南海诸岛范围，阿尔伯斯为 105°E/25°N·47°N 形态）。
4. 每幅图可见：左上指北针（N）、左下比例尺（km 标注）、右下图例（陆地/经纬网）、经纬网带经纬度标注。
5. 缩放按钮放大后：指北针/图例/比例尺位置不动，比例尺长度随倍率更新且标注仍为整千米数。
6. 按坐标查看模式行为与 spec/07 §2.4 一致（绿框、Tissot、规则结论、图例追加行）。
7. `npm run build`（vue-tsc）通过；离线渲染脚本可复现分组与整饰。
