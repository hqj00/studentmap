# spec/09 功能规格：投影总览分区展示（中国/世界成图）与图面整饰

版本 v0.2 · 2026-10-21 · 状态：已实现

## 1. 背景与目标

`/#/projection` 页底部的「投影总览 · 18 幅」（spec/07）目前按"投影面类别 × 变形性质"二维筛选，
18 幅缩略图混排，且图面只有陆地与经纬网，缺少地图学教学要求的基本整饰要素。

本规格做两件事：

1. **分区展示**：总览拆成两个模块——「中国地图投影」与「世界地图投影」。
   **两个模块都包含全部 18 种投影**，区别只在成图区域：前者把每种投影画在中国全图上，
   后者把同一种投影画在世界全图上，便于学生直接对比"同一投影在不同区域的效果差异"。
2. **图面整饰**：每幅缩略图都带指北针、比例尺、图例，经纬网加经纬度标注（标清经纬网）。

## 2. 分区展示

### 2.1 模块构成

| 模块 | 成图区域 | 幅数 |
|---|---|---|
| 中国地图投影 | 中国全图四至（含南海诸岛）：73.5°E~135.1°E / 3.8°N~53.6°N | 18 |
| 世界地图投影 | 世界全图（-180°~180° / -90°~90°），沿用 spec/07 §2.3 展示带退化规则 | 18 |

- 两组合计 36 幅；投影编号沿用知识库序号（1~18），同一投影在两个模块中编号相同。
- **不按"适用区域"对投影分类**——任何投影都会在两个模块中各出现一次。

### 2.2 渲染规则

- **中国组**：`buildPreviewLayers(..., { clipToExtent: true })`——球面、陆地、经纬网一律裁剪到中国全图四至，
  不画绿色范围框。投影参数走 `effectiveParams`（阿尔伯斯命中 105°E/25°N·47°N 惯例；高斯-克吕格取 105°E 带）。
- **世界组**：与 spec/07 §2.3 一致——圆锥类/横轴墨卡托用中纬教学展示带，墨卡托裁 ±85°，其余完整球面。
- **按坐标查看模式**：两个模块统一改为坐标范围（±55°/±35°），保留绿框、Tissot 与规则结论（与原行为一致）。
- 类别/性质筛选同时作用于两个模块；筛选后某模块为空则整组隐藏。

### 2.3 展示

- 组标题：「中国地图投影 · 18 幅」「世界地图投影 · 18 幅」。
- 顶部计数文案：`符合筛选：x / 18（每个模块）`。
- 总览卡片标题：`投影总览 · 18 种投影 × 中国/世界两种成图区域（共 36 幅）`。

## 3. 图面整饰（每幅必备）

### 3.1 经纬网标注（标清经纬网）

- 经纬网线为深绿虚线（`#8bab98`，线宽 0.7，虚线 2.5/2.5），叠于陆地之上，缩略图尺寸下清晰可辨。
- **经纬网间隔按成图范围取教学惯例值**：
  - 中国全图 / 展示带等区域图：10° 细网（中国全图经纬网惯例）；
  - 世界全图（圆柱 / 伪圆柱 / 折中类）：30° 网（世界挂图惯例，与参考效果一致）；
  - 方位类全球图：15° 网（极区/半球经纬圈更密，30° 只剩两三圈）；
  - 墨卡托等横跨 360° 的展示带：同样取 30° 网。
- 经纬度标注随图面缩放（是地图内容）：
  - **世界全图**：经度标注沿赤道（每 60°：120°W…0°…120°E；间距过近时自动省略），纬度标注沿中央经线（每 30°：60°S~60°N，赤道不重复标注）；方位类只标 ±60°（30° 标注会挤在投影中心）。
  - **区域图（中国组 / 展示带）**：经度标注沿下边缘、纬度标注沿左边缘，间隔按跨度自适应（目标 ≤7 条，步长取 2/5/10/15/20/30/45/60/90°，并做最小间距过滤）。
  - 标注为 5px 深绿字、白色描边光晕；落在画幅外或被图例/比例尺/指北针遮挡的自动省略。

### 3.2 指北针

- 每幅图左上角：N 字 + 箭头图符（深绿色，白描边），不随缩放移动。
- 说明：方位/极地类投影的"北"并非全图朝上，此处按教学挂图惯例放置概略指北针。

### 3.3 比例尺

- 每幅图左下角：黑白相间线段比例尺 + 千米标注（如 `1000 km`）。
- 长度由投影中心处比例（R / proj.scale()，R=6371000 m）换算，取最接近约 52px 的整千米数
  （候选 10/20/50/100/200/500/1000/2000/5000/10000/20000 km，上限 92px）。
- 不随缩放平移，但长度随当前缩放倍率重算——任意缩放级别下比例尺始终正确。

### 3.4 图例

- 每幅图右下角：白底圆角小框，标题「图例」，行项动态：
  - 常驻：陆地（浅绿块样例）、经纬网（虚线样例）
  - 按坐标查看模式追加：制图范围（绿框样例）、变形椭圆（橙圈样例）、标记点（橙点样例）
- 不随缩放平移。

### 3.5 实现位置

- `ZoomableMap` 新增 `overlay` 具名插槽：渲染在缩放变换组之外（不随缩放移动），
  带 `:scale` 插槽属性（比例尺据此重算），`pointer-events: none` 不影响拖拽与按钮。
- `d3Factory` 新增 `buildPreviewDecorations()`：返回经纬网标注数组与投影中心米/像素；
  `buildPreviewLayers()` 新增第 6 参 `opts.clipToExtent`（区域成图裁剪）。
- 整饰加在总览 36 幅（ProjectionGallery）与推荐方案预览（ProjectionPreview，v0.3 扩展）；
  投影实验室不在本规格范围。
- ProjectionPreview 的整饰样式全部内联（不依赖 scoped CSS），图例行随图面内容增减
  （制图范围只在非世界范围绘制时才出现），导出的独立 SVG / PNG 自带样式。

## 4. 验收

1. 总览分「中国地图投影 · 18 幅」「世界地图投影 · 18 幅」两个模块，合计 36 幅。
2. 同一投影在两个模块中的缩略图不同：中国组显示中国全图（含南海诸岛范围），世界组显示世界全图/教学展示带。
3. 类别/性质筛选同时作用于两个模块；筛选后空组隐藏；计数不变。
4. 每幅图可见：左上指北针（N）、左下比例尺（km 标注）、右下图例（陆地/经纬网）、经纬网带经纬度标注。
5. 缩放按钮放大后：指北针/图例/比例尺位置不动，比例尺长度随倍率更新且标注仍为整千米数。
6. 按坐标查看模式行为与 spec/07 §2.4 一致（绿框、Tissot、规则结论、图例追加行）。
7. `npm run build`（vue-tsc）通过；离线渲染脚本可复现两个模块与整饰。
