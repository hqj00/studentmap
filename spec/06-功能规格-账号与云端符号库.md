# 06 功能规格 · 账号与云端符号库（F4）

- 对应需求：FR-4.1 ~ FR-4.5
- 目标：每个同学用**自己的账号密码**登录，符号库**分别存储在各自账号下**（云端），换电脑也能取回。

## 1. 技术选型

**腾讯云开发 CloudBase**（认证 + 文档数据库 + Web SDK）：

- 免费额度对课程规模够用；无需购买/运维服务器，与 GitHub Pages 静态托管共存；
- 内置「用户名 + 密码」认证方式；文档数据库按安全规则做 per-user 隔离；
- 与项目已有的腾讯云 SCF 代理（server/ai-proxy.scf.cjs）同生态。

## 2. 数据模型与安全

集合 `symbol_libraries`：**一个用户一条文档**，`_id = 用户 uid`：

```json
{ "owner": "<uid>", "symbols": [SymbolRecord…], "updatedAt": 1718000000000 }
```

安全规则（控制台配置）：只允许本人读写本人文档。

```json
{
  "read": "auth.uid != null && doc._id == auth.uid",
  "write": "auth.uid != null && doc._id == auth.uid"
}
```

## 3. 交互流程

```
未登录（本地模式）→ 点页头「登录云账号」→ /login 注册或登录
→ 登录成功：拉取云端库 ↔ 本地库按 id 合并（并集）→ 写回本地并推送合并结果到云端
→ 之后库的每次变更（入库/删除/导入）防抖 800ms 自动推送云端
→ 退出登录：保留本地库，停止同步
```

- **降级**：未配 `VITE_TCB_ENV` 或未登录 → 纯本地模式（现状不变）；云端拉取/推送失败 → 本地仍可用，界面提示一次。
- 页头账号区：未登录显示「登录云账号」链接；已登录显示用户名 + 「退出」。

## 4. 控制台配置步骤（教师/部署者执行）

1. [cloud.tencent.com](https://cloud.tencent.com) 开通**云开发 CloudBase**，新建环境（按量计费有免费额度），记录**环境 ID**；
2. 环境 → 身份认证 → 登录方式：开启**用户名密码登录**；
3. 数据库：新建集合 `symbol_libraries`，权限改为「自定义安全规则」，填入 §2 的规则；
4. 环境 → 安全配置 → **安全域名**添加 `hqj00.github.io`（以及 localhost 用于本地调试）；
5. 项目 `.env` 增加 `VITE_TCB_ENV=<环境ID>`，重新 `npm run build` 并部署。

## 5. 环境变量

| 变量 | 说明 |
|------|------|
| `VITE_TCB_ENV` | CloudBase 环境 ID（前端构建期变量；不含任何密钥，CloudBase 前端 SDK 本就设计为公开调用，权限由安全规则兜底） |

## 6. 验收用例

| # | 操作 | 期望 |
|---|------|------|
| 1 | 未配 VITE_TCB_ENV 启动 | 应用正常工作，页头显示「登录云账号」 |
| 2 | 注册新账号并登录 | 页头显示用户名；云端集合出现该 uid 的文档 |
| 3 | A 账号入库符号 → 退出 → 登 B 账号 | B 看不到 A 的符号（安全规则隔离） |
| 4 | 登录前本地有 3 个符号，云端有 2 个不同符号 | 登录后合并为 5 个，云端同步为 5 个 |
| 5 | 登录状态入库新符号 | 约 1s 后云端文档更新（防抖） |
| 6 | 断网登录 | 提示云端不可用，本地模式正常 |

## 7. 演进

- 教师端：只读拉取本班所有学生的符号库（另开管理员安全规则或云函数聚合）；
- 符号库容量：单文档有大小上限，超出时提示导出备份（现状提示沿用）；
- 登录态持久化由 SDK 处理（localStorage 存凭据），长期免登。
