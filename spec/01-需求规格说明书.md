# 01 需求规格说明书

- 版本：v0.1（草案）
- 日期：2026-10-16
- 范围：studentmap **学生端**

## 1. 背景与目标

地图学课程中，「地图投影选择」与「地图符号设计」是两个核心实践环节：

1. 学生面对不同制图区域与用途时，往往不清楚该选哪种投影、参数如何设置；
   通用大模型（GPT / GLM / 通义千问等）具备地图学知识，可作为智能助教给出推荐与解释。
2. 地图符号设计需要专业工具链路：学生先用 **iconfont 的 AI 生成能力**快速获得基础符号素材，
   再在 **Illustrator** 中按制图规范精修，最终形成可入库、可复用的标准符号。

本项目目标是构建学生端 Web 应用，把上述两个环节数字化、流程化：

- **G1**：输入区域范围 + 地图用途 → 输出投影推荐（方案、参数、理由、预览）。
- **G2**：提供符号设计工作流引导与承接能力：素材获取（iconfont AI）→ 专业设计（Illustrator）→ 规范化入库（本应用）。

## 2. 用户角色

| 角色 | 说明 | 主要诉求 |
|------|------|---------|
| 学生（主要） | 地图学课程学习者 | 获得投影推荐并理解理由；按规范完成符号设计作业 |
| 教师（预留） | 课程教师 | 查看推荐记录与符号作业成果（本期不实现，架构预留） |

## 3. 功能性需求

### 3.1 地图投影智能推荐（F1）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-1.1 | 支持两种区域范围输入方式：预设区域（按「全球 / 中国 / 大洲与典型区域 / 极地」分组，范围取标准四至，中国全图含南海诸岛）与自定义经纬度包围盒（minLon/minLat/maxLon/maxLat） | 高 |
| FR-1.2 | 支持选择地图用途：普通参考、航海导航、统计专题、教学演示、大比例尺地形图、气象、极地制图 | 高 |
| FR-1.3 | 内置**规则引擎**：依据纬度带 × 用途 × 区域形状给出候选投影集与理由（离线可用） | 高 |
| FR-1.4 | 支持**大模型增强推荐**：调用通用大模型，结合候选集与投影知识库输出推荐排序、参数建议与自然语言解释 | 高 |
| FR-1.5 | 大模型不可用（超时/失败/未配置）时自动降级为规则引擎结果，并在界面明示来源 | 高 |
| FR-1.6 | 推荐结果展示：投影名称、类别、变形性质（等角/等积/等距/任意）、关键参数（中央经线、标准纬线）、推荐理由、来源标记（规则/AI） | 高 |
| FR-1.7 | 中国全图场景给出符合惯例的推荐：阿尔伯斯等积圆锥（双标准纬线 25°N、47°N，中央经线 105°E） | 中 |
| FR-1.8 | 投影结果可视化预览：推荐后直接渲染预览图，叠加经纬网与 Tissot 变形椭圆，直观对比面积/角度变形；绿框标出制图范围；**预览图可一键导出 SVG / PNG（供作业报告使用）** | 高 |
| FR-1.9 | 投影参数导出：一键复制 PROJ4 字符串与 WKT，给出 EPSG 提示（无对应编号时明示），输出中央经线、标准纬线、变形说明，可直接粘贴到 ArcGIS Pro / 超图 GIS | 高 |
| FR-1.10 | 制图范围可视化框选：内置小地图（等距圆柱+经纬网+经纬度标注），拖拽拉框自动读取四至填入自定义范围；手动输入仍保留 | 高 |
| FR-1.11 | 双方案对比：取前两名推荐并排展示（预览图、变形性质、参数、优缺点、适用场景），并生成「为什么优先 A」的对比结论 | 高 |
| FR-1.12 | 坐标试算：每个方案卡片内置正算/反算工具——输入经纬度输出投影平面坐标（x/y，米），输入 x/y 反算经纬度；计算所用投影定义与导出的 PROJ4 完全一致（同一份字符串），不支持试算的投影明确提示 | 高 |
| FR-1.13 | 参考影像图：方案卡片内预览图下方展示该投影的真实世界地图影像（Wikimedia Commons 自由许可图片，**已下载至 `public/ref-images/` 站内自带**，懒加载），上下结构并给出标注（投影名、作者、许可协议、来源）；加载失败优雅隐藏 | 中 |

### 3.2 地图符号设计（F2）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-2.1 | 提供符号设计**五步工作流**引导：①需求定义 ②iconfont AI 生成素材 ③Illustrator 专业设计 ④导入与规范化校验 ⑤入库与应用 | 高 |
| FR-2.2 | 步骤②给出 iconfont 网站入口与 AI 描述词（prompt）编写指引，帮助学生得到可用的基础 SVG 素材 | 高 |
| FR-2.3 | 步骤③给出 Illustrator 操作清单（画板网格、线宽、RGB 色彩、转曲、SVG 导出设置） | 中 |
| FR-2.4 | 支持上传 SVG 文件并进行**规范化校验**：根元素/viewBox、禁用脚本与外部引用、单色可换色建议等，输出问题清单 | 高 |
| FR-2.5 | 符号库管理：符号记录含名称、分类（点状/线状/面状）、标签、来源、创建时间；支持预览墙、删除、**导出与导入 JSON**（导入逐条规范化校验，不合格跳过并提示新增/跳过数量） | 高 |
| FR-2.6 | 符号数据本地持久化（localStorage），架构上预留后端持久化接口 | 中 |

### 3.3 智能符号设计（F3，v0.3 新增，独立页面）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-3.1 | 独立页面「智能符号设计」：学生用自然语言描述（如"我需要一个加油站的点状符号"），系统直接搜索并推荐相符的现成矢量符号，一键选用入库，无需五步向导 | 高 |
| FR-3.2 | 内置中文地物→英文检索词词库（约 30 个常见地物，可扩充）；描述命中词库自动转英文检索 | 高 |
| FR-3.3 | 候选符号网格展示；点选后一键入库：自动下载 SVG → 规范化校验（复用 F2 校验器）→ 入符号库（来源 `iconify`，与 F2 向导页共享同一符号库） | 高 |
| FR-3.4 | 保留 iconfont 直达入口：按关键词打开 iconfont 搜索结果页（外链新标签），供需要 iconfont 素材时使用 | 中 |
| FR-3.5 | 界面固定展示素材许可提示（Iconify 聚合的开源图标集许可 / iconfont 站点许可） | 高 |
| FR-3.6 | 数据源决策：iconfont 无公开搜索 API（2026-10 实测返回站点 HTML 壳），应用内搜索采用 Iconify 公共 API（免密钥、CORS 开放、纯静态托管可用）；详见 spec/05 §2 | 高 |

## 4. 非功能性需求

| 编号 | 类别 | 需求 |
|------|------|------|
| NFR-1 | 性能 | 规则引擎推荐 < 100ms；大模型推荐 120s 内返回（思考型模型/中转站首字可能 60s+），超时自动降级 |
| NFR-2 | 安全 | 大模型 API Key 仅存放于服务端代理，前端不持有密钥 |
| NFR-3 | 兼容性 | Chrome / Edge 最新两个大版本；桌面与移动端自适应（断点 768px），手机浏览器可完成全部流程 |
| NFR-4 | 可用性 | 全流程中文界面；关键步骤有引导与示例 |
| NFR-5 | 可维护性 | spec 先行；模块边界清晰（投影模块与符号模块相互独立） |
| NFR-6 | 版权合规 | 对 iconfont 素材给出许可提示，入库符号记录来源字段 |
| NFR-7 | 工程基建 | 构建前置 TypeScript 类型检查（vue-tsc）；push 到 main 由 GitHub Actions 自动构建并部署 Pages |

## 5. 边界与约束

- iconfont 网站与 Adobe Illustrator 为**外部工具**，不在本应用内实现其功能；
  本应用负责：流程引导、prompt 建议、设计规范清单、成果（SVG）的承接与校验。
- 投影推荐属于教学辅助，结果供学习参考；不替代国家法定测绘产品的投影规定。
- 本期为学生端单机/轻服务形态；教师端、账号体系、协作功能列入演进路线（见 04 架构设计）。

## 6. 验收标准（摘要）

1. 不联网（不配置大模型）时，输入「中国全图 + 统计专题」能返回阿尔伯斯等积圆锥投影，参数为 25°N/47°N/105°E，且标注来源为「规则」。
2. 配置大模型代理后，同一输入返回结果含自然语言解释且标注来源为「AI」；关闭代理后自动降级且不报错。
3. 上传一个含 `<script>` 的 SVG，规范化校验必须拦截并给出问题说明。
4. 完成一次符号入库后刷新页面，符号仍在库中。
5. 详细用例见各功能规格的「验收用例」章节。
