# 03 功能规格 · 地图符号设计

- 对应需求：FR-2.1 ~ FR-2.6
- 流程图：[diagrams/symbol-design-flow.mmd](diagrams/symbol-design-flow.mmd)

## 1. 功能概述

为学生提供一条**规范化的地图符号设计工作流**：
先在 iconfont 网站用 AI 生成基础符号素材，再导入 Adobe Illustrator 按制图规范精修，
最后导回本应用完成规范化校验与入库，形成可复用的课程符号库。

> iconfont 与 Illustrator 是外部工具，本应用提供：流程引导、AI 描述词建议、
> 设计规范清单、SVG 成果承接（上传→校验→入库→应用/导出）。

## 2. 用户故事

- 作为一名学生，我要设计「气象台站」点状符号，系统能引导我写出合适的 iconfont AI 描述词（如"天气站符号 线性风格 单色"），并获得基础素材。
- 作为一名学生，我能按清单在 Illustrator 里完成精修（统一 64px 网格、线宽、RGB、转曲、正确导出 SVG）。
- 作为一名学生，我上传精修后的 SVG，系统能告诉我是否合规（有没有残留脚本、外链图片、缺 viewBox 等），合规后入库并在预览墙看到效果。

## 3. 五步工作流定义

**交互形式（v0.2 起）：向导式分步界面。** 顶部步骤条与内容卡片一一对应，同一时刻只展示当前步骤，
通过「上一步 / 下一步」推进；当前步骤前置条件未满足时「下一步」置灰（如第 1 步未填名称、第 4 步校验未通过）。
设计目标：新用户无需通读全部说明，跟随向导逐步完成即可；步骤间数据自动携带（第 1 步的名称/分类/风格
自动用于第 2 步描述词与第 5 步入库表单）。

### 步骤 ① 需求定义

表单字段（均为简单选择/填空）：

- **地物名称**（必填，如"加油站""气象台站"）——未填不允许进入下一步；
- **符号分类**：点状 / 线状 / 面状（单选）；
- **风格**：线性 / 面性 / 剪影（单选）。

填写结果自动带入步骤 ② 的描述词模板与步骤 ⑤ 的入库表单，新手无需重复填写。

### 步骤 ② iconfont AI 生成基础素材

- 入口：<https://www.iconfont.cn>（站内设 AI 生成图标能力）。
- 应用内提供**描述词（prompt）模板**：

  ```
  {地物名称}地图符号，{风格：线性/面性/剪影}，单色，几何简洁，居中构图，无文字
  示例：加油站地图符号，线性风格，单色，几何简洁，居中构图，无文字
  ```

- 学生挑选最接近需求的 1~3 个素材，**下载 SVG**。
- 界面固定展示许可提示：iconfont 素材遵循其站点许可协议，课程作业使用需注明来源；入库时来源字段记为 `iconfont-ai`。

### 步骤 ③ Illustrator 专业化设计

应用内展示操作清单（checkbox 形式，可逐项勾选）：

1. 新建画板 64×64 px（点状符号基准），建立 4px 网格对齐；
2. 统一线宽（建议 2~4px，同组符号一致），必要时「对象 → 扩展」把描边转为填充；
3. 统一留白：符号内容距画布边缘建议 4~8px，同组符号一致；
4. 色彩模式 RGB；单体符号使用单色（便于入库后用 currentColor 换色）；
5. 全选文字 →「文字 → 创建轮廓」（转曲），避免字体依赖；
6. 删除多余锚点与隐藏图层，保持路径简洁；
7. 「文件 → 导出 → 导出为 → SVG」，设置：样式=内联、字体=轮廓、图像=不嵌入、对象 ID=最小化、小数位=2。

### 步骤 ④ 导入与规范化校验

上传 SVG（可多选），系统执行校验并输出**问题清单**：

| 级别 | 规则 | 说明 |
|------|------|------|
| 错误 | 根元素必须是 `<svg>`，且文档可解析 | 无法解析直接拒绝 |
| 错误 | 禁止 `<script>`、`<foreignObject>` | 安全要求 |
| 错误 | 禁止外部引用（`http(s):` 的 image/href、`@import`） | 保证离线可用 |
| 警告 | 缺少 `viewBox` | 若 width/height 为数值则自动补全 viewBox |
| 警告 | 包含未转曲文字 `<text>` | 提示回 Illustrator 转曲 |
| 警告 | **尺寸检查**：viewBox 非正方形 | 建议 64×64 基准正方形画板；仅提示不拦截 |
| 警告 | **线条检查**：检测到多种 stroke-width，或线宽 < 0.5px | 同组符号线宽应统一；过细缩放后不清 |
| 警告 | **配色检查**：填充色超过 3 种 | 地图符号用色应克制 |
| 建议 | 单色并使用 `currentColor` | 便于配图时整体换色 |

校验通过 → 进入步骤 ⑤；存在「错误」级问题 → 不允许入库，展示清单引导学生返回步骤 ③ 修正。

### 步骤 ⑤ 入库与应用

- 填写元数据：名称（默认取步骤①的地物名称，其次取文件名）、分类（取步骤①选择）、标签、来源（iconfont-ai / illustrator 原创 / 其他）。
- 点击「完成入库」后：提示成功、向导自动回到第 1 步便于连续设计下一个符号（分类/风格保留）。
- 符号库预览墙常驻页面下方：网格卡片展示 SVG 缩略（深/浅色底切换预览）、名称、分类；支持删除、整库导出 JSON。
- 数据持久化：localStorage（键 `studentmap.symbols.v1`）；架构预留后端同步接口。

## 4. 数据结构

```ts
type SymbolCategory = 'point' | 'line' | 'area'
type SymbolSource = 'iconfont-ai' | 'illustrator' | 'other'

interface SymbolRecord {
  id: string            // 生成：时间戳+随机
  name: string          // 如「气象台站」
  category: SymbolCategory
  tags: string[]        // 如 ["气象", "点状", "1:25万"]
  svg: string           // 规范化后的 SVG 文本
  source: SymbolSource
  createdAt: number
}
```

## 5. 设计规范依据

- 符号设计三要素：形状、尺寸、颜色；六视觉变量：形状、尺寸、方向、色相、明度、密度。
- 图式标准参考 GB/T 20257《国家基本比例尺地形图图式》（课堂讲解用，不要求应用内置图式库）。

## 6. 异常处理

| 场景 | 处理 |
|------|------|
| 上传非 SVG 文件 | 拒绝并提示「仅支持 .svg」 |
| SVG 超大（> 512KB） | 警告，提示回 Illustrator 精简路径 |
| localStorage 写满 | 捕获异常，提示导出备份后清理 |
| 同名符号 | 允许，按 id 区分；界面提示重复名称 |

## 7. 验收用例

| # | 操作 | 期望结果 |
|---|------|---------|
| 1 | 上传含 `<script>alert(1)</script>` 的 SVG | 校验报「错误」，不入库 |
| 2 | 上传无 viewBox 但有 width/height 的合法 SVG | 警告并自动补全 viewBox，可入库 |
| 3 | 入库后刷新页面 | 符号仍在预览墙 |
| 4 | 导出 JSON 后清空再导入（手工核对 JSON） | JSON 字段完整（id/name/category/tags/svg/source/createdAt） |
| 5 | 步骤 ② 面板 | 显示 iconfont 链接、描述词模板与许可提示 |
