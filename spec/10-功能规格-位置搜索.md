# spec/10 功能规格：位置搜索（地名检索自动成图范围）

版本 v0.1 · 2026-10-22 · 状态：已实现

## 1. 背景与目标

`/#/projection` 推荐表单的"区域范围"目前只有两种方式：预设区域下拉、自定义经纬度（手动输入或地图框选）。
学生最常用的意图是"给某个地方选投影"——中国某省、中国某市、世界某国——却要自己查经纬度，门槛高。

本规格新增「搜索位置」：输入/选择地名后自动换算为四至经纬度并立即触发投影推荐。

## 2. 数据源

内置地名检索表 `src/assets/places.json`（一次性离线生成，约 51KB / 685 条）：

| 分组 | 数量 | 数据源 |
|---|---|---|
| 世界国家 | 176 | Natural Earth 110m admin-0 countries（`NAME_ZH` 中文名 + 英文名；台湾/港澳剔除，由中国省份条目覆盖） |
| 中国省份 | 34 | 阿里云 DataV 省级行政区边界（与 spec/09 省界图层同源，含台湾省） |
| 中国城市 | 475 | 阿里云 DataV 逐省 `_full.json`（地级市；直辖市返回辖区） |

- bbox 取该要素**最大面片**的包围盒（排除海外领土/离岛把范围拉得过大），经纬度保留 2 位小数；
- 台湾省暂无市级数据（DataV 无对应文件），只有省份条目；
- 条目格式 `{ n: 中文名, e?: 英文名, t: c|p|y, p?: 所属省, b: [minLon,minLat,maxLon,maxLat] }`，
  模块 `src/modules/projection/places.ts` 提供分组列表与按键查找。

## 3. 交互

- 位置：推荐表单「区域范围」选**自定义经纬度**时，在地图框选下方显示「搜索位置」下拉。
- 下拉按「中国省份 / 中国城市 / 世界国家」三组排列，支持输入过滤（中英文均可匹配）；
  城市选项显示「市名 · 所属省」，国家选项显示「中文名 · 英文名」。
- 选中后：①把该区域四至填入自定义经纬度（数值可再手调）；②提示已填入；③**立即触发投影推荐**
  （与点「获取投影推荐」等效，规则引擎 + 可选大模型）。
- 与既有交互兼容：手动输入、地图框选、预设区域均可继续使用，互不影响。

## 4. 验收

1. 选「四川省」→ 四至自动填为四川范围，推荐结果出现（阿尔伯斯等积圆锥等）。
2. 选「成都市 · 四川省」→ 四至为成都范围，推荐结果出现（比例尺尺度变小）。
3. 选「日本 · Japan」→ 四至为日本范围，推荐结果出现。
4. 选中后仍可修改四至数值重新推荐；手动输入与框选不受影响。
5. `npm run build`（vue-tsc）通过。
