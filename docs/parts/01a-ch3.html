type MapPurpose =

3.3 规则引擎的三层判定

3.4 置信度合并与排序

同一投影可能被多条规则命中（例如“中国 + 统计”会同时命中特殊规则与中纬统计规则）。合并规则是按 id 取最高置信度，理由保留最先出现且置信度最高的一条；然后按置信度降序取前 4 条。

const byId = new Map<string, RuleHit>()
for (const hit of hits) {
  const prev = byId.get(hit.id)
  if (!prev || hit.confidence > prev.confidence) byId.set(hit.id, hit)
}
return [...byId.values()]
  .sort((a, b) => b.confidence - a.confidence)
  .slice(0, 4)
  .flatMap((hit) => {
    const projection = findProjection(hit.id)
    return projection ? [{ projection, reason: hit.reason,
      source: 'rule' as const, confidence: hit.confidence }] : []
  })

知识库中不存在的 id 在最后一步被丢弃，因此规则表里写错一个 id 不会让页面崩溃，只会少一条候选。

3.6 规则引擎的边界

  • 不新增规则：知识库从 12 条扩到 18 条时，规则引擎没有增加任何新规则；新增 6 条只服务总览与 AI 候选，避免“总览变多、推荐变味”。
  • 不按投影面类别硬筛：规则只看纬度带、用途、形状，不因为“中国在中纬”就排除圆柱投影；是否合适由理由与优缺点说明。
  • 不保证唯一正确答案：规则输出是教学建议，不是测绘生产结论；中国全图惯例参数是公开出版地图的常见做法，不替代法定标准。
  • AI 参数尚未接入有效参数：AI 返回的 params 会合并进知识库条目的 typicalParams，但预览 / 导出使用的 effectiveParams 仍从区域推导。这是已知限制，见 §14.4；它不影响推荐排序与理由。
