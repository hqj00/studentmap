4.5 PROJ4：单一事实源

导出与试算共用 buildProj4() 生成的同一份字符串。这是本项目最重要的一致性约束：用户在 ArcGIS Pro / 超图里粘贴的参数，与页面坐标试算的结果必须来自同一个定义。

// 中国全图 · 阿尔伯斯
+proj=aea +lat_1=25 +lat_2=47 +lat_0=0 +lon_0=105 \
+datum=WGS84 +units=m +no_defs

// 北京 · 高斯-克吕格（6° 带）
+proj=tmerc +lat_0=0 +lon_0=117 +k=1 \
+x_0=500000 +y_0=0 +datum=WGS84 +units=m +no_defs

横轴墨卡托固定假东 500 km（+x_0=500000），避免带内横坐标出现负值；墨卡托固定 +lat_ts=0；极地立体按南北半球取 +lat_0=+90 或 +lat_0=-90；折中与伪圆柱类只保留中央经线与基准。

4.6 WKT2 与 EPSG 方法编号
