5.2 定向：rotate 与 center 的分工

if (info.category === 'azimuthal') {
  proj.rotate([-cm, -originLat])
} else {
  proj.rotate([-cm, 0]).center([0, originLat])
}

方位投影把视点对准区域中心：rotate 同时旋转经度和纬度。其余投影只旋转经度，再用 center 把原点纬度平移到画幅中心。

横轴墨卡托是一个必须单独说明的坑：它不能靠 center 平移来对准中央经线，否则会把距中央经线 90° 的奇异区拉进画幅。代码统一走 rotate([-cm, 0])，让中央经线成为图幅中央。

经纬网线本身用离散间隔：区域图（中国组、展示带）10°，跨 360° 的世界全图 30°，方位类全球图 15°（30° 只剩两三圈，太稀）。经纬度标注的间隔另按跨度自适应，目标是跨度内不超过 7 条：

其中 是经度或纬度跨度；没有满足条件的步长时取 90°。标注步长与网线步长可以不同：中国全图用 10° 网线，标注也按 10° 步长；世界全图用 30° 网线，经度标注却每 60° 一条、纬度每 30° 一条，避免缩略图上挤成一团。

标注规则分两种：

  • 世界全图：经度沿赤道每 60° 标一条（120°W 到 120°E），纬度沿中央经线每 30° 标一条，赤道不重复；方位类只标 ±60°，避免 30° 标注挤在投影中心。
  • 区域图：经度沿下边缘、纬度沿左边缘，步长由式 (16) 决定，并做 16px 最小间距过滤。

标注会主动避让三个整饰区：左上指北针（26×26）、左下比例尺（104×22）、右下图例（74×44）。落在画幅外或避让区内的标注直接省略，不硬挤。标注字号 5px、白色描边光晕，属于地图内容，随图面缩放。

6. 投影总览：18 × 2 = 36 幅

6.1 两个模块的语义

总览不是“把 18 种投影按适用区域分成两组”，而是同一套 18 种投影，分别在中国全图和世界全图上各画一遍。中国模块 18 幅、世界模块 18 幅，合计 36 幅；同一投影在两个模块中编号相同，方便直接对比“同一种投影在不同区域的效果差异”。

默认显示中国模块。模块选择框切换后，只渲染当前模块的 18 幅；组标题、计数、筛选结果同步更新。两个模块都保留类别、性质、姿态三个筛选器，以及“按坐标查看”“允许拖动”两个开关。

6.3 摆放姿态：正轴 / 横轴 / 斜轴

姿态按该幅图的实际定向逐幅判定，同一投影在两个模块可能不同。方位投影看投影中心纬度；横轴墨卡托固定横轴；其余类别为正轴。

横轴墨卡托 / 高斯-克吕格始终记横轴；圆柱、圆锥、伪圆柱、折中类记正轴。于是中国模块中以中国中心（约 35°N）定向的 4 个方位投影是斜轴，世界模块中中心在赤道、记横轴；世界模块筛“斜轴”会得到空态，中国模块筛“斜轴”得到 4 幅——这正是验收用例 4 的预期。

6.6 筛选组合与空态

类别（圆柱 / 圆锥 / 方位 / 伪圆柱 / 折中）、性质（等角 / 等积 / 等距 / 折中）、姿态（正轴 / 横轴 / 斜轴）三个筛选器可组合使用，结果为交集。计数显示“符合筛选：N / 18”；交集为空时显示空态提示，不渲染空白网格。
