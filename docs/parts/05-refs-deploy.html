同日修复世界视图的展示带：圆锥极点扇形、墨卡托默认 clipExtent、横轴墨卡托奇异区导致 fitExtent 包围盒失真的问题；展示带内陆地与经纬网按经纬度矩形裁剪后再投影。

总览升级为“同一套 18 种投影 × 中国 / 世界两种成图区域 = 36 幅”，增加模块选择、姿态分类、中国全图适用性三级标注；每幅补齐经纬度标注、指北针、比例尺、图例。整饰层不随缩放移动，比例尺按缩放倍率重算。推荐方案预览同步加上整饰，导出 SVG / PNG 自带内联样式。

15. 部署与运行

15.1 本地

npm install
npm run dev        # 前端 http://localhost:5173
npm run server     # 可选：AI 代理 http://localhost:8787
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览 dist

本地开发时 Vite 把 /api 代理到 http://localhost:8787，前端代码不需要处理跨域。AI 代理从 .env 读取密钥；.env 不入库。

15.2 GitHub Pages

构建产物是纯静态文件。路由用 hash 模式（/#/projection），资源用相对路径（base: './'），因此子路径部署不需要服务端回退配置。push 到 main 后 GitHub Actions 自动构建并推送 gh-pages；npm run deploy 是手动备选。

仓库 Variables 需要配置构建期公开变量：VITE_TCB_ENV（CloudBase 环境 ID）、VITE_AI_BASE_URL（SCF 函数 URL）。VITE_ 变量会进入前端产物，不是密钥；真正的密钥只在 SCF 环境变量与本地 .env。

15.3 AI 代理（SCF Web 函数）

  1. 腾讯云 → 云函数 SCF → 新建 Web 函数，运行时 Node.js 18；
  2. 函数 URL：公网访问启用，授权类型“开放”（免鉴权）；
  3. 环境变量：LLM_API_KEY、LLM_BASE_URL（只填到 /v1）、LLM_MODEL、ALLOW_ORIGIN=https://hqj00.github.io、PORT=9000；
  4. 把 server/ai-proxy.scf.cjs 全文粘贴进模板 app.js，保留模板其他文件不动；
  5. 执行超时调到不少于 120 秒（默认 3 秒不够；启用退避重试时更长）；
  6. 复制函数 URL，写入仓库变量 VITE_AI_BASE_URL，重新构建部署。

代理只做三件事：保管密钥、转发 OpenAI 兼容 /chat/completions、超时与错误透传。它不区分推荐 / 助手 / 问答，业务语义全在 system prompt 与前端解析。
