这份文档回答三个问题：推荐结果为什么是它、图上的每一个点为什么落在那里、符号与账号数据在什么条件下会丢。它面向三类读者——要理解推荐理由的学生、要复核实现是否与规格一致的教师、以及接手代码的开发者。

文档只记录已经进入代码的行为。规划中的能力集中在 §14.4，不与已实现内容混写。所有公式、阈值、参数表都能在仓库中找到对应实现；公式编号 (1)–(34) 供交叉引用，不复刻教材推导。

阅读约定：坐标一律写作 （经度、纬度），单位度；平面坐标写作 ，单位米； 仅用于教学预览与比例尺，PROJ4 导出与坐标试算使用 WGS84 椭球。代码块为 TypeScript / JavaScript 摘录，省略 import 与样式。

1. 文档范围与系统边界

1.1 五个页面与三条链路

studentmap 是一个纯静态可部署的 Vue 3 单页应用。页面按功能分为五个路由，底层归并为三条链路：

表 1 · 路由、视图与离线可用性
路由视图承担的功能断网时
/#/projectionProjectionRecommendView投影推荐、双方案对比、投影实验室、36 幅总览、参数导出、坐标试算规则推荐、预览、导出、试算均可用

三条链路分别是：

  1. 投影链路：区域 + 用途 → 规则引擎（必跑）→ 可选 AI 增强 → 有效参数 → d3 预览 / 图面整饰 → PROJ4 / WKT / 坐标试算；
  2. 符号链路：描述或向导 → iconfont / Illustrator / Iconify → SVG 规范化校验 → 符号库 →（登录后）CloudBase 同步；
  3. 自然语言链路：问答或教学助手 → AI 代理 → 合法 JSON / 文本 → 确定性校验与状态变更；失败时分别落到离线 FAQ 与离线指令解析器。

1.2 坐标、单位与数据口径

系统只做投影数学与教学示意，不做大地基准转换。具体口径如下：

  • 输入输出统一为 ，经度 ，纬度 ；
  • 不做 WGS84 / CGCS2000 / 北京 54 / 西安 80 的基准转换，不做 GCJ-02 / BD-09 偏移纠偏，不处理高程；
  • 预览与总览使用球面近似 ；PROJ4 定义带 +datum=WGS84，坐标试算由 proj4js 按椭球计算；
  • 页面输出的米制坐标不是 EPSG:3857；Web 墨卡托只在知识库提示中出现；
  • 中国全图参数（105°E / 25°N / 47°N）是公开出版地图的教学惯例，不替代国家法定测绘产品的投影规定。

运行形态的关键事实：唯一的服务端组件是 AI 代理。其余全部在浏览器内完成；未配置 VITE_AI_BASE_URL 时，应用仍是一个完整的离线可用工具。CloudBase 是托管 BaaS，不是自建后端，权限由数据库安全规则兜底，前端不持有密钥。

1.4 不做什么

  • 不实现 iconfont 站内搜索 API，也不嵌入 Adobe Illustrator——两者是外部工具，本应用只做引导、prompt、校验与承接；
  • 不做瓦片地图、不做地形晕渲、不做距离量算（教学助手对“距离”类请求只标注位置）；
  • 不做教师端、作业提交、多人协作；账号体系只服务“每人自己的符号库”；
  • 不把 AI 输出当作事实源：AI 只能选择知识库内的投影、解释理由、把自然语言解析为受限动作；数学计算与状态变更由确定性代码执行。

2. 功能目录与固定顺序

2.1 投影知识库：18 条固定条目

2.3 模块依赖

projection/
  presets.ts      → 区域预设、18 条知识库、中国适用性
  ruleEngine.ts   → 特征提取 + 三层规则 + 合并排序
  params.ts       → 有效参数（中央经线 / 标准纬线 / 分带）
  d3Factory.ts    → 投影实例 + 图层 + 图面整饰
  exporters.ts    → PROJ4 / WKT / EPSG 提示
  convert.ts      → proj4js 正算 / 反算（消费 exporters 的字符串）
  aiClient.ts     → AI 增强推荐（失败即抛出，由视图降级）
  assistant.ts    → 实验台状态机 + 离线指令解析 + AI 动作契约

symbol/
  types.ts        → SymbolRecord
  standardize.ts  → SVG 规范化校验（唯一安全入口）
  iconify.ts      → 中文词库、Iconify 搜索、SVG 下载
  transfer.ts     → JSON 导入合并（逐条重新校验）
  library.ts      → localStorage store + 登录后云同步

cloud/            → CloudBase 开关、认证、拉取 / 推送 / 合并
qa/               → 问答 AI 通道 + 离线知识库

依赖方向是单向的：ruleEngine 依赖 presets，convert 依赖 exporters，library 依赖 transfer 与 cloud；反向不成立。投影模块与符号模块互不引用，可以独立测试与演进。
